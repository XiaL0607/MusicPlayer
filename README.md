智能音箱项目基于全志 H618 开发套件，可以实现听歌以及 AI 聊天功能。音 箱具备三种控制方式：按键、APP 以及语音。 项目分为三个部分，嵌入式端、云服务器以及 APP，都是我一个人完成。 嵌入式端基于 select 多路复用技术，主进程可以同时监听按键、网络以及 语音识别，其中语音识别是通过管道跟主进程通信的。 播放部分采用多进程实现。父进程负责监听指令；子进程负责创建孙进程， 然后阻塞，等孙进程结束后回收资源；孙进程通过 execv 函数启动 mplayer，既 能播放本地音乐，又能播放在线音乐。其中，在线音乐是我自己基于云服务器搭 建的音乐服务器。三个进程使用共享内存传递数据，并且加上信号量来保护共享 数据。语音识别部分使用 sherpa 推理引擎，在开发板上部署训练好的大模型，可 以实现语音识别、关键词唤醒、语音合成三个功能，这三个功能跟主进程之间都 是通过管道来通信。 后台云服务器我用的是阿里云服务器，主要完成了两个功能：一是搭建在线 音乐平台，二是负责管理所有音箱设备和 APP。服务器端用的 C++语言，基于 libevent 高并发框架，可以同时处理多个音箱设备和 APP。数据处理上使用了 MySQL 数据库和链表，数据库存储 APP 的登录、绑定信息，链表用于转发数据时 查询使用。 APP 采用 Qt 图形框架，一是显示音箱当前的状态和歌曲信息，二是往服务 器发送控制指令，包括切歌、调节音量、播放模式等等。
